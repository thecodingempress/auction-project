A Django-based auction platform built as part of Harvard's CS50 Web Programming with Python and JavaScript course.

**What it does:**
- Create listings with a title, description, starting bid, and image
- Place bids on active listings
- Add listings to a watchlist
- Leave comments on listings
- Close a listing to declare the highest bidder the winner
- Browse listings by category
  
**Built with**
- Python / Django
- HTML & CSS
- SQLite
- Django's built-in authentication
